# JobPilot CN

中国市场、本地优先、支持多账号数据隔离的AI求职工作台原型。

线上版本：https://jobpilot-cn.pages.dev

## 当前版本（本地可运行 MVP）

- DOCX/PDF简历真实解析并写入本地事实库
- 批量粘贴JD、关键词提取、薪资/地点/出差规则和匹配评分
- 批量生成真实DOCX岗位版简历，保留事实约束与差距提示
- 投递审批队列、状态历史、重复投递拦截
- Playwright可见浏览器准备模式：持久登录会话、批量打开岗位页、尝试填姓名/电话/邮箱、保存运行结果，永不点击最终提交
- BOSS直聘、智联招聘、猎聘及通用ATS的首版站点适配器
- 浏览器原生中文语音识别/朗读模拟面试，答案评分与会话持久化
- 面试问题与答案本地题库
- 当前账号与用户数据以本地 `data/store.json` 保存，不依赖云数据库；旧 `state.json` 仅作为迁移快照来源
- 手机号注册、验证码校验、密码登录、HttpOnly会话Cookie与退出登录
- 每个账号独立保存简历、岗位、定制版本、投递、面试和题库
- 生成简历按账号鉴权下载，`data/`运行数据不可通过网页直接访问
- Cloudflare Pages Functions版本使用D1保存账号/用户状态，KV暂存私有简历文件

## 尚未完成

- 未接入云端或本地LLM，当前匹配与改写是规则引擎
- 当前多用户存储仍是本地JSON，正式公网部署前需要迁移到PostgreSQL/MySQL并加入备份、事务和管理后台
- 云端版本已使用D1，不再依赖本地JSON；后续仍需拆分JSON状态表、增加并发控制与备份恢复
- 开发环境验证码显示在注册页；生产环境需配置 `SMS_WEBHOOK_URL` 和可选的 `SMS_WEBHOOK_TOKEN`
- BOSS直聘、智联、猎聘适配器已具备页面识别与字段提示，但尚需在用户真实账号和真实岗位页面逐站联调选择器
- 登录、验证码必须用户处理；任何真实投递都必须用户在动作前确认
- DOCX视觉模板仍是基础版，尚未实现多模板和PDF渲染验收

## 启动

```powershell
npm run dev
```

打开 http://127.0.0.1:4173

## 验收测试

服务启动后运行：

```powershell
npm test
```

## 安全设计

- 个人资料默认本地存储
- 不绕过验证码和平台风控
- 不执行静默海投
- 上传和最终提交前明确预览与批准
- 不提供真实面试中的隐蔽代答
